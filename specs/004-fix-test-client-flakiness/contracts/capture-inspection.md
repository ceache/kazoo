# Contract: Network Capture Inspection for Session Validation

**Feature**: `004-fix-test-client-flakiness` | **Date**: 2026-08-29 | **Spec**: [spec.md](../spec.md)

## Purpose
Defines the procedures, expectations, and packet filter invariants for verifying ZooKeeper connection negotiation and session expiration via packet captures generated by `--zk-features=capture`.

## Capture Execution & Output Schema

### Running Capture
```bash
pytest kazoo/tests/integ/test_client.py -k test_request_queuing --zk-features=capture -s
```

### Artifact Layout
When capture is enabled, the integration test harness produces the following per-member PCAP files in the temporary test directory (e.g. `/tmp/kazoo-.../`):
- `kazoo-capture-zoo1.pcap`
- `kazoo-capture-zoo2.pcap`
- `kazoo-capture-zoo3.pcap`

## Packet Invariants

### 1. Initial Connection Handshake
- **Client Frame**: TCP SYN -> ACK -> ZooKeeper `ConnectRequest`
  - Opcode / Protocol: `0` (Connect)
  - `protocolVersion`: `0`
  - `lastZxidSeen`: `0`
  - `timeOut`: `30000` ms (or client-configured session timeout)
  - `sessionId`: `0x0`
  - `passwd`: 16 zero bytes (`00000000000000000000000000000000`)
- **Server Frame**: ZooKeeper `ConnectResponse`
  - `protocolVersion`: `0`
  - `timeOut`: Negotiated positive integer (e.g. `30000`)
  - `sessionId`: Server-allocated 64-bit ID (e.g. `0x1000...`)
  - `passwd`: 16 non-zero random token bytes

### 2. Mangled Password Connection Attempt
- **Client Frame**: ZooKeeper `ConnectRequest`
  - `sessionId`: `0x[previous_session_id]`
  - `passwd`: Mismatched 16 bytes (mangled byte 0)
- **Server Frame**: ZooKeeper `ConnectResponse`
  - `protocolVersion`: `0`
  - `timeOut`: `0` (or `<= 0`) -> **Session Expired / Rejected Indicator**
  - `sessionId`: `0x0`
  - `passwd`: 16 zero bytes

### 3. Immediate Reconnection with Clean Session
- **Client Frame**: ZooKeeper `ConnectRequest`
  - `sessionId`: `0x0`
  - `passwd`: 16 zero bytes
- **Server Frame**: ZooKeeper `ConnectResponse`
  - `timeOut`: `30000`
  - `sessionId`: `0x[new_allocated_session_id]`

## Inspection CLI Recipe (tshark)
```bash
# Display all ZooKeeper connect negotiations from zoo1 capture
tshark -r /path/to/kazoo-capture-zoo1.pcap -Y "tcp.port == 2181" -T fields \
  -e frame.number -e ip.src -e ip.dst -e zookeeper.session_id -e zookeeper.timeout
```
